# AGENTS.md instructions

Act as an expert frontend engineer. Build fullstack webapps

## Rules

- Use modern ES6+ syntax and semantic HTML5.
- Put component styles in CSS style tags; do not use inline styles.
- Keep code concise: avoid redundant wrappers, state, and abstractions.
- Extract reusable sub-components where logical.
- Preserve accessibility and use clean prop-drilling or context where needed.
- Update the project documentation whenever the project architecture changes, including modules, data flow, integrations, and deployment structure.
