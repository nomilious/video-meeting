# Issue tracker: Local Markdown

Issues and specs live in `.scratch/<feature>/`.

- Spec: `spec.md`.
- Tickets: `issues/<NN>-<slug>.md`, numbered from `01`, one file per ticket.
- Record triage state in a `Status:` line near the top; PRD publication uses `ready-for-agent`.
- Append conversation under `## Comments`.
- To publish, create the corresponding markdown file. To fetch, read the referenced file.
