# 02: Скачивание оригинала файла встречи

**What to build:** Владелец скачивает выбранный файл встречи и получает полный оригинал, доступный после перезапуска приложения.

**Blocked by:** 01 — Загрузка и отображение файлов встречи.

**Status:** ready-for-agent

- [ ] У каждого сохранённого файла есть доступное действие скачивания; выбор одного файла не скачивает другой.
- [ ] API отдаёт оригинальные байты как вложение с безопасным именем и запретом MIME-sniffing. Внутренний ключ хранения не раскрывается.
- [ ] Скачивание требует серверной проверки авторизации, владельца встречи и принадлежности файла этой встрече. Чужой или отсутствующий ресурс возвращает 404, отсутствие авторизации — 401; токен не передаётся в URL.
- [ ] UI показывает выполнение и понятную ошибку скачивания, обрабатывает истечение сессии и освобождает временные браузерные ресурсы.
- [ ] Согласованный сквозной сценарий с реальным API проходит полностью: создать встречу, загрузить файл, обновить страницу, увидеть метаданные, скачать и сравнить байты оригинала.
- [ ] Проверено сохранение доступности и целостности оригинала после перезапуска API с тем же постоянным хранилищем; API-тесты подтверждают изоляцию аккаунтов и встреч.
- [ ] Документированы скачивание, резервное копирование БД вместе с файлами и восстановление; проходят затронутые проверки типов и lint.
