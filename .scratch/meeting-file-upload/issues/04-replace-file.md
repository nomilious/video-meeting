# 04: Безопасная замена файла встречи

**What to build:** Владелец выбирает новый файл вместо существующего; при успешной замене видит новые метаданные, а при неудаче сохраняет доступ к оригиналу.

**Blocked by:** 01 — Загрузка и отображение файлов встречи.

**Status:** ready-for-agent

- [ ] Для выбранного файла доступно действие замены с выбором нового файла и явной отправкой. Остальные файлы встречи сохраняются.
- [ ] Замена возможна и при заполненном лимите 3 файлов, не создаёт четвёртый видимый файл и не требует предварительного удаления оригинала.
- [ ] Новый файл проходит те же серверные ограничения размера и содержимого, что первичная загрузка. Авторизация, владение и принадлежность файла проверяются сервером.
- [ ] Оригинал остаётся доступным до полного сохранения нового файла и успешной фиксации метаданных. Ошибка чтения, записи, проверки или транзакции не уничтожает оригинал.
- [ ] После успеха UI показывает новые имя, размер, тип и время загрузки; после обновления страницы сохраняется тот же результат. Новый оригинал доступен через API содержимого; проверка байтов не требует завершения задачи 02.
- [ ] Повторная отправка блокируется, состояние выполнения и ошибки доступны пользователю. При неопределённом результате запроса сначала перечитываются метаданные; не происходит повторной замены уже успешно сохранённого результата без явного действия.
- [ ] Конкурирующие замены и удаление не вызывают потерю актуального файла или появление частично сохранённой записи. Устаревшая операция отклоняется предсказуемым конфликтом.
- [ ] Незавершённые новые объекты очищаются при штатных сбоях. Старые объекты удаляются только после успешного переключения; предусмотрена безопасная сверка и очистка остатков после аварии.
- [ ] Сквозная проверка покрывает успешную замену и отображение после обновления страницы; API-проверки — сохранение оригинала при отказе, конкуренцию, лимит и изоляцию; браузерные — ошибки и повторные действия.
- [ ] Контракт замены и генерируемые типы обновлены; проходят затронутые проверки типов и lint. Документированы замена и очистка объектов.
